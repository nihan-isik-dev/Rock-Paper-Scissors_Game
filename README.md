# Python Tkinter Rock Paper Scissors Game

A desktop Rock-Paper-Scissors game with a dark theme interface built using Python's `tkinter` library. Developed as part of an AI-assisted (**vibe coding**) practice project.

## 🚀 Key Features
* **Decoupled Architecture:** Core game logic (`determine_winner`) is completely separated from the Tkinter GUI interface.
* **Score Tracker:** Persistent score state for Player, Computer, and Draws with a reset functionality.
* **Modern Dark UI:** Clean visual design matching standard dark mode aesthetics.

## 🛠️ Installation & Running

Ensure Python 3 is installed.

### Linux (Fedora / Ubuntu)
If `tkinter` is missing, install it via package manager:

```bash
# Fedora:
sudo dnf install python3-tkinter

# Ubuntu/Debian:
sudo apt-get install python3-tk
